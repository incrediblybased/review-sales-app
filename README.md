# Review Signal

Can public customer reviews (Amazon, Steam) tell us how a company's sales are doing before it reports?
Six studies, pre-registered tests, leave-one-company-out scoring. Short answer: reviews move a little with sales,
mostly for Steam-centred publishers, but do not beat a company's own recent growth trend.

Run locally: `pip install -r requirements.txt` then `streamlit run streamlit_app.py`.

Personal research project. Not investment advice. Steam review data: CC BY-NC 4.0 (non-commercial).
