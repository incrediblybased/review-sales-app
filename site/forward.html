Collecting new data from now on

Forward collection

Every Sunday at 11:00 (when this PC is on) a scheduled task records the running review totals for about 2,600 tracked games from SteamSpy. The difference between snapshots gives new reviews per quarter. After a year or two this allows a test on quarters that did not exist when the rules were written.

Managing the task

Task name
ReviewSignalWeeklySnapshot
Output
D:\review-signal-nowcast\forward\
Run now
schtasks /Run /TN ReviewSignalWeeklySnapshot
Remove
schtasks /Delete /TN ReviewSignalWeeklySnapshot /F
